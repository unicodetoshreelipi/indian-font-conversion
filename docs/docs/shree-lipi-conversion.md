# Unicode to Shree Lipi Conversion

## What Is Shree Lipi?

Shree Lipi is a legacy Indian font system associated with
Hindi and Marathi typing, DTP, printing and publishing
workflows.

It is still encountered when working with older documents,
templates and production environments.

## Why Unicode Needs Conversion

Unicode Hindi or Marathi text cannot normally be converted
into a Shree Lipi workflow by simply changing the selected
font.

The underlying text representation must be processed using
the appropriate character mapping.

## Basic Workflow

1. Prepare Hindi or Marathi text in Unicode.
2. Submit the Unicode text to a compatible converter.
3. Convert the text to the required Shree Lipi representation.
4. Copy the converted output.
5. Apply the required Shree Lipi font.
6. Verify the result in the target DTP application.

## Font Installation

The required Shree Lipi font should be installed on the target
system. Without the appropriate font, converted legacy text
may appear as Latin characters or other unexpected symbols.

## Important

Different legacy font families can have different mappings.
Always verify the target font and conversion method before
using converted text in production.
