# Indian Language DTP and Legacy Font Workflow

## Modern Unicode Workflow

For modern websites and applications, Unicode is generally the
preferred text representation.

Typical workflow:

Typing
  ↓
Unicode Text
  ↓
Unicode Font
  ↓
Modern Application
  ↓
Web / Digital Publishing

## Legacy DTP Workflow

Older production environments may require a legacy font system.

Typical workflow:

Unicode Text
  ↓
Conversion
  ↓
Legacy Text
  ↓
Legacy Font
  ↓
DTP Application
  ↓
Printing / Publishing

## Why Conversion Matters

Changing the font alone does not necessarily change the
underlying text representation.

If a DTP application expects a legacy representation, the
Unicode text may need to be converted first.

## Common Applications

Legacy Indian-language workflows can be encountered in:

- PageMaker
- CorelDRAW
- Adobe InDesign
- Adobe Photoshop
- QuarkXPress

## Recommended Practice

Keep the original Unicode text as the master copy whenever
possible.

Use a converted legacy representation only when required by
the target production workflow.

This makes future migration, web publishing and text reuse
much easier.
