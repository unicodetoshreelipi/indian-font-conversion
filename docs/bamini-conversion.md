# Unicode to Bamini Conversion

## What Is Bamini?

Bamini is a legacy Tamil font system used in older Tamil
typing, DTP and publishing workflows.

Unlike modern Unicode Tamil text, Bamini-based workflows use
their own text representation.

## Why Unicode Tamil Looks Wrong in Bamini

If Unicode Tamil text is copied directly into a Bamini-based
workflow and only the font is changed, the result can appear
as unrelated Latin characters or incorrect symbols.

This happens because the text representation has not been
converted.

text should be tested before final printing.
