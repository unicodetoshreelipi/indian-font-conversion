# Conversion Examples

These examples demonstrate the difference between Unicode text
and legacy-font workflows.

## Hindi / Marathi

### Unicode

The source text should remain stored as Unicode whenever
possible.

Example:

मराठी भाषा

### Legacy Workflow

The Unicode text can be processed through the appropriate
legacy-font conversion workflow when a DTP system requires
Shree Lipi or a related font.

Online tool:

https://unicodetoshreelipi.com/

## Tamil

### Unicode

தமிழ் மொழி

### Legacy Workflow

When a production workflow requires Bamini, the Unicode Tamil
text needs to be converted before the Bamini font is applied.

Online tool:

https://unicodetoshreelipi.com/unicode-to-bamini-converter

## Important

These examples demonstrate workflow concepts rather than
publishing a proprietary character-mapping table.
