# Indian Font Conversion

A reference project for understanding Unicode and legacy Indian
font systems used in typing, DTP and publishing workflows.

## Supported Font Systems

- Shree Lipi
- Shree Dev
- Bamini
- Kruti Dev
- Shree Guj
- Unicode

## Unicode vs Legacy Fonts

Unicode stores the actual character identity independently
of the font.

Legacy Indian fonts may use font-specific character mappings.
Because of this, simply changing the font does not convert
legacy text into Unicode.

## Conversion Workflow

Unicode Text
↓
Character Mapping
↓
Legacy Font Encoding
↓
DTP Application

## Why Conversion Is Required

Changing a font does not necessarily change the underlying
character encoding. Legacy text may need to be converted
using an appropriate character mapping before it can be
used as Unicode.
